# NutriVidas

Sistema de gestão de distribuição de comida para moradores de rua da ONG Nutri Vidas.
Projeto Integrador Extensionista ADS.

## Requisitos

- Git
- Vite+ (comando vp): https://viteplus.dev

## Como rodar

1. Clone o repositório e entre na pasta:
   ```bash
   git clone [https://github.com/SEU-USUARIO/nutrividas.git](https://github.com/SEU-USUARIO/nutrividas.git)
   cd nutrividas
   ```
